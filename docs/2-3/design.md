## 🔌 接口设计

### JavaScript函数

#### `updateClock()`
- **功能：** 更新时钟显示
- **调用频率：** 每秒执行一次
- **实现逻辑：**
  1. 获取当前时间（Date对象）
  2. 提取小时、分钟、秒
  3. 格式化为两位数（补零）
  4. 更新DOM元素内容

#### 辅助函数 `padZero(num)`
- **功能：** 将单位数字前补零
- **参数：** `num` - 数字
- **返回值：** 格式化后的字符串（如：05, 12）

## 💡 实现思路

### 1. HTML结构
- 使用语义化标签
- 创建时钟容器 div
- 分别创建时、分、秒的显示区域
- 添加分隔符（冒号）

### 2. CSS样式设计
- **背景：** 纯黑色 `#000000`
- **文字颜色：** 青色/绿色 `#00ff00` 或 `#0ff`
- **字体：** 等宽字体（monospace）或数字专用字体
- **发光效果：** 使用 `text-shadow` 实现多层阴影
- **布局：** Flexbox 实现水平垂直居中
- **字体大小：** 响应式设计，使用 vw 单位

### 3. JavaScript逻辑
```javascript
// 伪代码
function updateClock() {
  const now = new Date()
  const hours = padZero(now.getHours())
  const minutes = padZero(now.getMinutes())
  const seconds = padZero(now.getSeconds())
  
  // 更新DOM
  document.querySelector('.hours').textContent = hours
  document.querySelector('.minutes').textContent = minutes
  document.querySelector('.seconds').textContent = seconds
}

// 每秒更新
setInterval(updateClock, 1000)
// 立即执行一次
updateClock()
```

### 4. 用户体验优化
- 页面加载时立即显示时间（不等待第一个间隔）
- 平滑的视觉效果
- 良好的可读性
- 全屏显示，无滚动条
