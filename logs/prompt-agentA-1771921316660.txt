## 🎯 命名规则（强制执行）

### Vue组件命名规则

1. **组件注册名称** 使用 PascalCase
   ```javascript
   // ✅ 正确示例
   OwSelect4Search
   ```

2. **模板使用** 必须用 kebab-case
   ```vue
   <!-- ✅ 正确示例 -->
   <ow-select4-search />
   ```

3. **数字和字母之间** 必须加短横线
   ```
   ❌ 错误：select4search
   ✅ 正确：select4-search
   ```

4. **文件名** 使用 kebab-case
   ```
   ✅ 正确：ow-select4-search.vue
   ```

5. **import 路径** 使用实际文件名
   ```javascript
   // ✅ 正确示例
   import OwSelect4Search from './ow-select4-search.vue'
   ```

> ⚠️ **重要提示：** 组件注册成功但不渲染，99%是命名约定问题！
