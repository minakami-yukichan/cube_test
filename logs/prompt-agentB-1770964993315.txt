```142:174:src/clock.html
    <script>
        function padZero(num) {
            return num.toString().padStart(2, '0');
        }

        function updateClock() {
            const now = new Date();
            
            // 更新时间
            const hours = padZero(now.getHours());
            const minutes = padZero(now.getMinutes());
            const seconds = padZero(now.getSeconds());
            
            document.querySelector('.hours').textContent = hours;
            document.querySelector('.minutes').textContent = minutes;
            document.querySelector('.seconds').textContent = seconds;
            
            // 更新日期
            const year = now.getFullYear();
            const month = padZero(now.getMonth() + 1);
            const date = padZero(now.getDate());
            const weekdays = ['星期日', '星期一', '星期二', '星期三', '星期四', '星期五', '星期六'];
            const weekday = weekdays[now.getDay()];
            
            document.querySelector('.date-display').textContent = 
                `${year}年${month}月${date}日 ${weekday}`;
        }

        // 立即执行一次
        updateClock();
        
        // 每秒更新
        setInterval(updateClock, 1000);
    </script>
```

## ✅ 完成要求（重要！）

完成检查后，**必须**输出以下标准 JSON 格式（不要包含其他解释文字）：

### 如果 ESLint 检查通过：
```json
{
  "code": 200,
  "msg": "代码质量检查通过",
  "data": {
    "reqId": "2-3",
    "status": "passed",
    "checks": {
      "lint": {"passed": true, "errors": [], "warnings": []}
    },
    "summary": "ESLint 检查通过，代码质量良好"
  }
}
```

### 如果 ESLint 检查失败：
```json
{
  "code": 500,
  "msg": "代码质量检查失败",
  "data": {
    "reqId": "2-3",
    "status": "failed",
    "checks": {
      "lint": {
        "passed": false, 
        "errors": [
          "文件路径:行号:列号 - 错误描述 (规则名称)"
        ],
        "warnings": [
          "文件路径:行号:列号 - 警告描述 (规则名称)"
        ]
      }
    },
    "failureDetails": "详细的 lint 错误信息和具体的修复建议，供 Agent A 理解如何修复"
  }
}
```

⚠️ 格式要求（严格遵守）：
1. **code 字段**：通过时必须是数字 200，失败时必须是数字 500
2. **status 字段**：必须是字符串 "passed" 或 "failed"
3. **reqId 字段**：必须包含需求编号 2-3
4. **checks 字段**：只包含 lint 检查项
5. **不要添加任何额外的解释文字**，只输出纯 JSON 格式
6. **🔥 字符串值中必须转义换行符**：如果 failureDetails 或 errors 包含多行文本，必须使用 \n 转义，不要用真实换行！例如："failureDetails": "第一行\n第二行\n第三行"
7. **推荐使用紧凑格式**：输出单行 JSON 可避免格式问题

🚨 **status 判断规则（绝对不能违反）**：
- ✅ **status = "passed"** 的条件：
  - **lint.passed === true** （必须！）
  - **lint.errors 数组为空或不存在** （必须！）
  - 只要 ESLint 没有 error 级别的问题，就算通过

- ❌ **status = "failed"** 的条件：
  - **lint.passed === false**，或
  - **lint.errors 数组有内容**
  - 任何一个不满足就是 "failed"

⚠️ **注意事项**：
- warnings（警告）不影响通过状态，只有 errors（错误）才会导致失败
- 如果只有 warnings 没有 errors，status 应该是 "passed"
- 必须详细记录每个 error 的文件路径、行号、列号和错误描述
